# LinkedList
# ADA4 - MyLinkedList

Entrega para la Unidad 3 (Estructuras Lineales). Implementación de una lista simplemente ligada en Python.

## Archivos del repositorio

- **MyLinkedList.py**: Es la biblioteca donde está programada la clase `LinkedList` y la estructura de los nodos (`INFO` y `LIGA`).
- **main.py**: Es el archivo principal que importa la biblioteca `MyLinkedList` y tiene el menú para hacerla funcionar.
- **nodos.py**: Es un programa aparte donde están los nodos y las funciones (insertar al inicio/final, antes o después de un elemento, eliminar, recorrer y buscar) todo junto en un solo archivo.

## Cómo ejecutarlo

Para probar la biblioteca desde el archivo principal:
```bash
python main.py
